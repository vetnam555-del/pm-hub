# 벤치마크 없음 오류 수정

기준일: 2026-09-07. 수정 기준: v32 / 0662164.

## 확인된 원인

- `전체` 기기 필터가 PC/MO 자료를 제외하고 원본에 `전체`로 표기된 자료만 선택했다. 구글만 자료가 있는 일부 업종에서 트래픽 구성도 막혔다.
- `MO` + 설치 목표에서 Android/iOS로 구분된 구글 자료가 제외됐다.
- 필터 결과 0건을 모두 같은 alert 문구로 표시해 자료 부재와 정책상 제외를 구분할 수 없었다.
- 브라우저별 로컬 자료 저장이라는 한계가 빈 결과 화면에 충분히 설명되지 않았다.

## 수정

- `전체`는 모든 기기를 대상으로 검색하되 PC/MO/OS별 단가와 전환 정의를 유지한다. 통합 자료와 분할 자료를 동시에 배분하지 않는다.
- `MO` 설치 계획은 Android/iOS를 각각 구성할 수 있다. 다른 기기의 단가를 임의로 복사하지 않는다.
- 구성 전 사용 가능한 자료 수, 업종과 선택 조건, 비용 기준/기기/목표/단가/참고값/피드/모수별 제외 사유를 표시한다.
- 0건일 때 생성 버튼을 비활성화하고 참고값 허용, 전체 기기 조회, 피드·모수 조건 확인, 업종 자료 조회 및 가져오기 경로를 제공한다. 조건 변경은 사용자가 버튼을 누른 경우에만 적용한다.
- 실패 시 기존 계획을 삭제하지 않는다. 남아 있는 수치가 이전 계획임을 명시하고 변경 후 다시 검토하도록 한다.
- 작성일 변경도 자동 계산의 근거 기준일에 반영한다.

## 검증 및 한계

- 전체 기기, 통합/분할 중복 제외, 모바일 OS, 비용/목표/기기/참고값별 진단, 업종별 트래픽 전체 기기 순회 회귀 테스트를 추가했다.
- 화면에서 실제 0건 조건을 만든 후 해결 버튼으로 복구되는지, 저장/수정/예산/VAT/엑셀/PDF/모바일 흐름까지 재검증한다.
- 자료가 없는 업종, 기준 미확인 비용, 서로 다른 전환 정의에 대한 제한은 해제하지 않는다.
- 현재 인앱 탭은 업종 미선택 상태였다. 사용자가 오류를 본 정확한 조합은 별도 확인 요청했으며, 사용자 조합과 재현된 결함을 동일하다고 단정하지 않는다.
- 비공개 자료는 브라우저별 로컬 저장이다. 공개 배포나 다른 브라우저 자동 동기화를 이번 수정으로 제공하는 것은 아니다.
