# 미디어믹스 실무 사용 최종 검수

검수일: 2026-09-07 / 수정 버전: v28

## 결론

브랜드별 근거를 선택하고 예산·단가·전환 정의를 검토한 뒤, 미디어믹스 예상안과 XLSX/PDF를 만드는 용도로 사용할 수 있습니다.
기존 v27에서 추가 오류를 재현해 수정했습니다. 모든 조건에서 오류가 없거나 최신 광고 단가가 자동 검증되는 제품이라는 의미는 아닙니다.

## 추가 발견 및 수정

| 중요도 | 발견 내용 | 수정 및 검증 |
| --- | --- | --- |
| 높음 | 잘못된 비율 문자열을 숫자로 변환하면 null이 되고, 비교식에서 0처럼 취급되어 제출 검수를 통과할 수 있었음 | 숫자 유효성·범위·빈칸을 분리 검증. 비정상 문자열, 빈 VAT/마크업, 잘못된 쉼표, 정수 예산, 0 역산 비율 회귀 테스트 추가 |
| 높음 | 백업의 활성 계획만 검사해 저장된 계획의 구조 오류를 놓침 | 모든 저장 계획, 필드 타입, 확인 체크의 boolean 타입 검사. 손상된 브라우저 원본은 자동 덮어쓰지 않고 복원 전 백업 유지 |
| 중간 | 계획의 광고주·기간·예산이 변경되어도 이전 검토 체크가 남음 | 계획 변경·복제 시 재검토 요구 |
| 중간 | 입력칸에서 포커스가 나갈 때 전체 폼을 교체해 다음 클릭을 놓칠 수 있음 | 입력칸을 유지하고 계산 결과만 갱신. 연속 입력·첫 클릭 저장 확인 |
| 중간 | 동영상 조회·앱 설치·메시지 발송 물량이 주 제출 화면에서 충분히 드러나지 않음 | 편집표·PDF에 단위별 예상 물량 표시, XLSX 미디어믹스 시트에 별도 물량표 추가. 클릭과 발송 합산 금지 유지 |
| 중간 | PDF에서 캠페인별 출처·운영 조건을 확인하기 어려움 | 출처, 근거 성격, 기준일, 행 기간, 기기, 타기팅, 비고 포함 |
| 중간 | XLSX의 실제 날짜 셀을 거부하고 백분율 셀을 100분의 1로 잘못 해석할 수 있음 | 근거 날짜 셀을 ISO 날짜로 변환, 백분율 표시 셀을 퍼센트포인트로 변환. VTR·전환 정의 가져오기 지원 |
| 중간 | 동일 ID의 다른 자료를 가져오면 충돌 여부가 표시되지 않음 | 신규·중복·내용 충돌 건수를 사전 표시. 기존 값 유지, 다른 버전은 새 ID로 관리 |
| 중간 | 정액형의 역산 물량은 엑셀에서 상수였고 일부 긴 출처가 잘릴 수 있음 | 독립 물량만 입력값 유지, 파생 물량은 수식 연결. 텍스트 행 높이와 개별 인쇄 헤더 보완 |

## 검증 결과

- 계산·입력·백업 테스트: 33개 통과.
- 기존 허브 30개 경로: 렌더링 및 테스트 중 미처리 JavaScript 오류 없음.
- 데스크톱 1440×1000, 모바일 390×844 화면 검토.
- 실제 가져오기: 제공된 비공개 자료팩 38건 유지 가능, 기본값·중복 충돌·잘못된 백업 검사.
- 브라우저 입력 포커스, 첫 클릭 저장, 승인 무효화, 계획 저장·재열기, 시나리오 선택 검사.
- XLSX 날짜·백분율 셀 변환 검사.
- CPC 단일 예제와 CPC/CPM/CPV/CPI/SEND/FIXED 혼합 예제: LibreOffice 독립 재계산 235개 숫자 셀 일치, 수식 오류 없음.
- 혼합 예제의 엔진 대비 출력 108개 항목 대조. 조회·설치·발송 별도 표 대조.
- 혼합 예제 PDF 1페이지의 물량·산출 근거 텍스트 및 렌더링 확인.
- 고객 원본·비공개 데이터팩은 공개 저장소에 포함하지 않음.

검증 예제는 합성 데이터입니다. 모든 광고주 계약, 모든 엑셀 수정 조합, 모든 브라우저 및 프린터를 검증한 것은 아닙니다.

## 제출 전 필요한 확인

1. 실제 광고주 계약의 마크업과 청구 VAT 기준을 입력합니다. 플랫폼 이름만으로 세금 처리를 확정하지 않습니다.
2. 단가는 수수료·VAT 제외 실매체비 기준, 행 예산은 수수료 포함·VAT 별도 공급가입니다.
3. 과거 제안과 실적을 구분하고, 최신 집행 조건에 맞는 단가·CTR·CVR·객단가를 검토합니다.
4. 구매·리드·설치 정의를 확인합니다. 제공되지 않은 전환율이나 매출을 임의로 생성하지 않습니다.
5. 정액 계약의 물량·기간과 선결제 여부를 확인합니다. 예산이나 기간을 바꿔도 정액 예상 물량이 자동 비례 조정되지는 않습니다.
6. 필수 검수를 통과한 후 제출용 XLSX 또는 PDF를 출력합니다. 엑셀 수정을 한 경우 브라우저 검수 결과는 내보내기 시점의 기록이므로 재검수·재출력합니다.

## 남은 범위

- 실무 계획·출력 도구이며 광고 구매, 플랫폼 API 동기화, 최적 예산 배분을 보장하는 예측 모델은 아닙니다. 자동 배분은 입력한 고정 예산과 가중치를 따릅니다.
- 브라우저 전용 저장입니다. 팀원·기기 간 자동 공유와 권한 관리, 실시간 공동 편집은 없습니다. JSON 백업·가져오기로 이동합니다.
- 공통 단가와 과거 자료는 현재 성과를 보장하지 않습니다. 신뢰할 최신 실적 데이터의 지속적인 보강은 별도 운영 업무입니다.
- 월별 세부 페이싱·실적 대비 집행 모니터링은 이번 미디어믹스의 총기간 예산·행별 기간 계획과 별개의 기능입니다.
- 외부 매체 정책과 허브의 모든 교육 콘텐츠가 최신이라는 보증은 하지 않습니다.

위 항목은 숨겨진 완성 조건이 아니라 현재 제공 범위의 경계입니다. 팀 운영 시스템이나 자동 집행 시스템으로 확장할 경우 별도 설계가 필요합니다.
